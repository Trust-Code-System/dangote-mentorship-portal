# Full platform evidence

This directory contains safe generated or seeded-demo evidence only. It contains no credentials, cookies, tokens, private production participant files or secret environment values.

- `certificate/`: safe certificate preview/PDF samples (complete set also in `certificate-evidence/`).
- `public/`: desktop/mobile public screenshots.
- `mentee/`, `mentor/`, `admin/`: current route-sweep screenshots.
- `localization/`: French messages workspace after remediation.
- `capacity/`: local read-only public-load result (complete evidence also in `capacity-evidence/`).
- `authentication/`, `permissions/`, `messages/`, `ai/`, `files/`, `accessibility/`, `performance/`: evidence is test/report based; unsafe external mutations were not fabricated. See `FULL_PLATFORM_TEST_MATRIX.md` and `FULL_PLATFORM_DEFECT_LOG.md`.

The `browser/` folder is the direct Playwright output. Categorized copies are retained for audit handoff.
