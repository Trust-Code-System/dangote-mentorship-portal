## Design Context

### Users
Dangote mentorship programme administrators, mentors and mentees manage accounts, matching, goals and sessions. Preserve the existing role-specific workflows and records.

### Brand Personality
Premium, clear and composed. The owner requested a sharp, polished interface with soft, restrained motion, compact header spacing and the supplied original logos.

### Aesthetic Direction
Maintain the established light workspace, forest accents, neutral controls and role-specific dashboards documented in `.ui-craft/brief.md`. Sign-in is the entry page. Avoid persistent green control outlines and decorative language chips or switchers.

### Implementation Defaults
Preserve the existing Next.js App Router, React, TypeScript, Tailwind CSS and local shadcn/Radix wrappers. Existing forms use server actions or React Hook Form with Zod; tables use the existing semantic table components. Use these established components and tokens first.

### Design Principles
- Align related controls and match their heights before adding decoration.
- Group related actions with consistent gaps and keep helper text with its field.
- Adapt layout to available component width; prevent mobile overflow.
- Preserve keyboard focus, labels, reduced motion and existing behavior.
- Keep data and permissions real and unchanged during visual refinements.
